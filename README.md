# Body_line

Лендинг массажного салона и учебного центра «Body_line» (г. Крымск, ул. Пролетарская, 55).

- `index.html` — одностраничный сайт на React и Tailwind CSS (подключаются через CDN, сборка не нужна). Откройте файл в браузере.
- `docs/Body_line_landing_texts.docx` — структура страницы и тексты блоков.

## Что настроить
- Форма заявки в блоке «Обучение» пока не отправляет данные: подключите сервер, CRM или Telegram-бота в функции `submit` (комментарий `TODO`).
- Фото сертификата: задайте `CERT` в начале скрипта (data URI или путь к файлу). Пока пусто, блок скрыт.
- Укажите программу, даты и стоимость обучения.
